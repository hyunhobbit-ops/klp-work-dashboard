# AI 광고 소재 제작 메뉴 — 설계 (2026-07-02)

## 목적
회사 대시보드에 **"AI 광고 제작"** 메뉴를 추가한다. 제품을 넣으면 AI가 **광고 문구 + 이미지**를 만들고,
앱이 이를 **카톡·이메일 배포용 이미지**와 **A4 인쇄용 전단**으로 합성해 내보낸다.

## 핵심 원칙 (품질·안정성)
- AI에게 "완성된 광고 이미지(텍스트 포함)"를 통째로 시키지 않는다 — AI는 이미지 안의 한글을 제대로 못 씀.
- **역할 분리 + 앱 합성** 파이프라인:
  - **문구(카피)**: LLM(Claude/GPT)이 생성 (헤드라인·본문·CTA·해시태그·이메일 제목/본문)
  - **이미지**: 이미지 생성 모델(OpenAI gpt-image, Google Gemini/Imagen)이 **배경/장면**만 생성
  - **합성**: 앱이 템플릿(HTML/Canvas, 기존 `doc-generator` 방식 재사용)에 **또렷한 한글 텍스트 + 제품/배경 이미지**를 얹어 최종물 생성
- 서버리스 함수가 API 키를 프록시 (키는 서버에만, 로그인 직원만 호출 — 기존 `api/analyze-delivery.js` 패턴).

## 단계(Phase) 로드맵
전체 범위(A4+카톡+이메일 × 이미지 2방식 × AI 3종)는 크므로 나눠 만든다. **본 스펙은 Phase 1(MVP)만** 상세화한다.

- **Phase 1 (MVP, 본 스펙)**: 카톡·이메일용 **정사각 이미지 1종 + 카피 세트**. 이미지=**얹기 방식(AI 배경 + 제품 카드)**, 이미지 생성=**OpenAI만**, 카피=**Claude(기존 키)**. → 품질·비용 검증.
- **Phase 2**: A4 전단 템플릿 + 이미지 **2방식 비교**(얹기 + 녹이기, OpenAI+Gemini).
- **Phase 3**: 캠페인 저장·재사용, 템플릿 다양화, 이메일 전용 가로 배너.

## Phase 1 (MVP) 상세 설계

### 사용자 흐름
1. 사이드바 **"AI 광고 제작"**(편의성 그룹) 진입.
2. **제품 입력** — 둘 중 택1:
   - 기존 **상품 DB에서 선택**(이미지·이름·가격·옵션 자동 로드), 또는
   - **즉석 업로드**(제품 사진 1장 + 이름 + 가격(선택) + 핵심 포인트 몇 줄).
3. **광고 설정** 입력: 목적(예: 신제품 홍보/할인/브랜딩), 톤(예: 고급/친근/재미), 타깃(예: 20~30대), 강조 문구(선택).
4. **[생성]** 클릭 →
   - 서버가 **카피 3안**(각: 헤드라인·서브·본문·CTA·해시태그·이메일 제목/본문) 생성 (Claude).
   - 서버가 **배경 이미지 2장** 생성 (OpenAI gpt-image, 제품 없는 배경/장면; 정사각 1024²).
5. **결과 화면**: 배경 2장 + 카피 3안을 카드로 보여줌. 사장님이 **배경 1개 + 카피 1개 선택**, 카피 **문구 직접 수정** 가능.
6. **미리보기**: 선택한 배경 위에 **제품 카드(제품 사진을 둥근 프레임에 배치) + 헤드라인/가격/CTA(또렷한 한글)** 를 앱이 합성한 정사각 이미지.
7. **[내보내기]**:
   - **이미지 다운로드**(정사각 PNG) — 카톡·SNS 배포용.
   - **문구 복사**(카톡 메시지용 / 이메일 제목·본문) — 버튼으로 클립보드 복사.
8. **[저장]**: 캠페인으로 저장(다시 열어 수정/재내보내기).

> MVP의 이미지 합성은 **"AI 배경 + 제품 카드(프레임) + 텍스트"** 포스터 스타일이다. 제품을 배경에 매끄럽게
> 오려붙이거나(누끼) 장면에 녹이는 것은 **Phase 2**로 미룬다. (누끼/블렌딩은 별도 처리·비용 필요)

### 구성요소 (컴포넌트 / 인터페이스)
- **프론트(app.js, 새 탭 `tab-ad-studio`)**
  - `renderAdStudio()` — 입력 폼(제품 선택/업로드 + 설정) 렌더.
  - `generateAdMaterials()` — 입력 수집 → `/api/ad-copy`, `/api/ad-image` 호출 → 결과 상태 저장 → 결과 렌더.
  - `renderAdResults()` — 배경/카피 선택 UI + 문구 편집.
  - `composeAdImage()` — 선택된 배경+제품+텍스트를 Canvas/HTML로 합성(기존 html2canvas 재사용) → PNG.
  - `saveAdCampaign()` / `loadAdCampaigns()` — Supabase 저장/불러오기.
- **서버리스 함수 (의존성 최소, 로그인 토큰 검증 필수)**
  - `api/ad-copy.js` — 입력(제품·설정) → Claude Messages API(도구로 JSON 강제) → `{ variants: [{headline, sub, body, cta, hashtags, emailSubject, emailBody}] }`.
  - `api/ad-image.js` — 입력(장면 프롬프트) → OpenAI 이미지 API → base64 PNG 배열. (프롬프트는 제품 카테고리/톤 기반, **제품 없는 배경/무드**만 생성.)
  - 두 함수 모두 `api/analyze-delivery.js`처럼 **Supabase access_token 검증 → 없으면 401 / 키 미설정 503 / 사용자 친화 에러 매핑**.
- **DB (Supabase)**
  - 새 테이블 `ad_campaigns`: `id, created_at, author, product_id(nullable), product_snapshot(jsonb: 이름·가격·이미지), settings(jsonb), copy(jsonb: 선택 카피), bg_image(text: 선택 배경 base64/URL), status`.
  - RLS: authenticated 풀 액세스(기존 단순 모델).

### 데이터 흐름
제품/설정 입력 → (병렬) `ad-copy`(Claude) + `ad-image`(OpenAI) → 결과 선택/편집 → 클라이언트 Canvas 합성 → 다운로드/복사/저장.

### 에러 처리
- 키 미설정(OpenAI/Anthropic) → 503 + "관리자가 API 키를 등록해야 합니다" 안내.
- 이미지 생성 실패/한도초과(429)/부적절 콘텐츠(400) → 사용자 친화 토스트 + 재시도 버튼.
- 카피/이미지 중 하나만 실패해도 나머지는 표시(부분 성공 허용).
- 생성은 시간이 걸리므로 로딩 표시("AI가 만드는 중… 최대 30초").

### 준비물 (사용자, 1회)
- **OpenAI API 키 + 결제 등록** → Vercel 환경변수 `OPENAI_API_KEY`.
- Anthropic 키는 이미 있음(`ANTHROPIC_API_KEY`). (Gemini는 Phase 2)

### 비용
- 카피: 매우 저렴(요청당 수십 원 이하).
- 이미지: OpenAI 이미지 장당 대략 수십~수백 원 × 2장 = **생성 1회당 수백 원** 예상. (재생성 시 추가)

### 범위 밖 (Phase 1 제외 — 이후 단계)
- A4 전단 템플릿, 이메일 가로 배너, 제품 누끼/장면 블렌딩, Gemini 병행, 캠페인 대량 관리·통계.

  공유 파일 수정은 최소·국소화. 매 작업 전 원격을 먼저 받아 합침(rebase).
