2. **이카운트 회계는 정리가 안 된 상태** — 손익계산서는 "10월 이후 수정 전표 재집계" 경고, 회계집계표 당기순이익 -3.06억, 보통예금 -6,937만. 결산은 세무사 쪽에서 따로 하는 것으로 보임. → **대시보드가 이카운트 회계 숫자를 원본으로 쓰면 안 됨.**
3. **연동은 메뉴만 있고 꺼져 있음** — 홈택스 인증서는 등록(2026-07-09, 만료 2027-07-13, 발행·수집 가능), 카드매입·은행(기업은행 2계좌) 메뉴 있음. 하지만 2026년 수집 데이터 **0건**, 카드사는 미등록.

## 3. 데이터를 어디서 가져올까 — Aside가 이카운트를 대신 조작 (2026-11-10 결정)

중개 API(볼타·팝빌·바로빌) 대신 **대시보드 버튼 → 맥미니 → Aside → 이카운트**로 간다. 이카운트에 홈택스 인증서(발행·수집 가능, 2027-07-13 만료)와 기업은행 2계좌가 이미 등록돼 있고, Aside가 이카운트 계산서 발행을 이미 하고 있어서 추가 비용 없이 장부도 이카운트 한 곳에 남는다.

```
대시보드 버튼 ─→ aside_jobs 한 줄(종류·날짜만, 지시문은 넣지 않음)
                    │
맥미니 tax-worker(LaunchAgent) ─ 5초마다 확인 ─→ 종류별로 정해 둔 지시문으로 `aside mcp` exec
                    │                                  (대시보드 전용 Aside 채팅 1개, 한 번에 1건)
                    ↓
       Aside가 이카운트 화면 조작 → 엑셀 내려받기 → 작업기가 읽어서 tax_ledger에 넣음
                    ↓
       aside_jobs 상태(대기·진행 중·완료·실패) + 결과 글 → 대시보드에 바로 표시(realtime)
```

- **지시문은 작업기 안에 고정**: 대시보드에서 자유 문장을 보내지 않는다(누가 버튼을 눌러도 정해진 일만). 날짜 같은 값만 형식 검사 후 넣는다.
- **매일 새벽 자동**: 작업기가 하루 한 번(06시 이후 첫 확인) 매입/매출장 가져오기를 스스로 줄 세운다.
- **이카운트 매입/매출장 엑셀 양식**(2026-11-10 확인): 시트 `매입 매출장`, 1행 회사명·기간, 2행 머리글 `일자-No. | 유형명 | 전자구분 | 거래처명 | 세부내역 | 매입공급가액 | 매입부가세 | 매출공급가액 | 매출부가세`, 거래행은 `2025/01/02 -1` 형식, 사이사이 `2025/01 계 (35 건)` 월계·`누계`·출력시각 줄은 건너뜀. 유형명: 세금계산서·계산서·세금계산서(수입)·카드매출·영세율, 전자구분: 전자-신·착오·계약해제 등(착오는 음수 금액).
- **다시 가져오기**: 같은 기간의 이카운트 행을 지우고 새로 넣는다(DB 함수 `tax_ledger_replace` 한 번에). 손으로 넣은 행·영수증 행은 안 건드림.
- **카드**: 이카운트 카드매입조회 › 연동대상등록에 카드사 인증정보(인증정보명·카드사·카드사ID·비밀번호·사업자번호)를 **현호님이 직접** 넣어야 수집이 시작됨(2026-11-10 Aside가 입력 창까지 띄워 둠). 개인카드·간이영수증은 사진 입력(다음 단계).
- **계산서 발행**(다음 단계): `발행 준비` 작업(판매입력·매출전표까지 하고 발행 창 직전에서 멈춤, 금액·받는 메일·캡처를 돌려줌) → 대시보드에서 확인한 사람이 `발행 승인` → 그 한 건만 발행. 두 작업으로 나눠 되돌릴 수 없는 발행을 막는다.
- **한계**: 한 건에 1~5분, 맥미니·Aside가 켜져 있어야 함, 이카운트 화면이 바뀌면 지시문 보정 필요, 작업은 한 줄로 차례대로. 실패하면 결과에 이유를 남김.

## 4. 화면 구성 (안)

1. **이번 달 / 올해 누계 손익** — 매출 · 매출원가(매입 − 재고 증감) · 판관비 · 영업이익, 작년 같은 달과 비교. 매출은 채널별(세금계산서 / 카드·쇼핑몰 / 해외).
2. **부가세 미리 보기** — 현재 신고기간(10~12월 → 2027-01-25 확정신고)의 매출세액 − 공제 가능 매입세액 = 예상 납부(환급)액, D-day. 불공제 후보(접대비, 비영업용 승용차 등) 따로 표시.
3. **연말 법인세 미리 보기** — 누적 이익 + 남은 달 예상으로 과세표준·세액 추정(세율·공제는 설정값, 세무사 확인 후 입력).
4. **자금 흐름** — 기존 자금확인 잔액 + 은행 입출금 → 월별 들어온 돈·나간 돈, 다가오는 큰 지출(부가세·원천세·4대보험·이자·외상매입금).
5. **비용 입력함** — 영수증 사진 끌어다 놓기 → AI가 날짜·가맹점·사업자번호·금액·부가세·계정 제안 → 확인만 누르기. 카드 승인 내역 중 증빙 없는 건 표시.
6. **계산서 발행** — 국내 프로젝트·상담의 "계산서 발행" 단계에서 Aside에게 발행 준비를 시킴. 발행 전 공급가·부가세·합계·받는 메일을 한 화면에서 확인 후 발행(되돌릴 수 없으므로 2번 확인).
7. **AI 세무 체크** — 매월 1일, 신고 30일·7일 전에 카톡 나에게 보내기로 알림.

## 5. 지금 데이터로 AI가 미리 짚을 것 (예시)

1. **2026 매입이 매출보다 빨리 늘었음(+35% vs +8%)** — 재고로 남은 것인지, 매출이 이카운트 밖에서 일어난 것인지 확인. 연말 재고 실사 금액이 법인세에 직접 영향.
2. **2기 확정 부가세(2027-01-25)** — 10월 이후 장부상으로는 매입세액이 더 많아 환급 가능성. 단 이카운트 밖 매출(카드·쇼핑몰·해외)을 합치면 달라지므로 그 매출부터 모아야 정확.
3. **사장님 개인 비씨카드 1,457만** — 회사 경비로 처리하려면 건별 증빙 정리 필요. 접대비성 지출은 부가세 공제 안 됨.
4. **접대비** — 2026년 이미 605만(작년 117만). 한도 안이지만 3만원 넘는 건은 적격증빙(법인카드·세금계산서) 필수.
5. **이자비용 1,800만 vs 영업이익 1,900만(2025)** — 차입 구조 점검. 단기차입 1.22억 만기 확인.
6. **퇴직급여** — 연말 전에 퇴직연금 납입하면 올해 비용. 2025년엔 2,421만 처리.
7. **세액공제 후보(세무사 상담용)** — 고용 증가 시 통합고용세액공제, 특허·실용신안 보유 → 연구개발 세액공제 요건 해당 여부.
8. **이카운트 장부 정리** — 회계집계표 순손실 -3억, 보통예금 마이너스는 전표 누락 신호. 결산 전에 세무사와 맞출 것.
